Shado Guesser

Software Specification
Version 1.0

1. システム概要

Shado Guesser は、 Shadowverseのカードを推理して当てるブラウザゲームである。

プレイヤーはカード名を入力し、 表示される判定結果をもとに、 隠されたカードを推理する。

ゲームシステムは Poke Guesserをベースとした推理ゲームであり、 Shadowverse独自のカード情報 （クラス・コスト・能力など） を利用して遊ぶ。

2. 開発目的

  • Shadowverseプレイヤー向けの推理ゲームを制作する。
  • 初心者でもカードを覚えられる教材として利用できる。
  • 長く遊べるWebゲームを目指す。
  • 新カード追加後も継続して利用できる設計とする。
  • PC・スマートフォン双方に対応する。

3. コンセプト

項目 内容

想定プレイ時間 2〜10分

4. 基本ルール

  1. 答えとなるカードが決定される。
  2. プレイヤーはカード名を入力する。
  3. 入力カードと答えを比較する。
  4. 比較結果を履歴へ追加する。
  5. 答えを当てたらゲーム終了。

5. ゲームの特徴

  • Shadowverse公式カードデータを利用する。
  • カード名は完全一致で判定する。
  • カード能力から推理するゲームではなく、 カード情報全体から推理するゲームである。
  • カード追加にも対応可能な設計とする。
  • デイリーモードを搭載する。
  • 対戦モードを搭載する。
  • 出題モードを搭載する。
